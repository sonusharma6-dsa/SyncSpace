Feature 3
Real-time Document Editing
⚡

Live Collaboration

Changes broadcast to all members via Socket.IO within ~100 ms

🖱️

Cursor Presence

See other users' cursors in real time with colour-coded name labels

💾

Auto-Save (500 ms)

Debounced save after every keystroke — you never lose work

⚠️

Conflict Resolution

2-second detection window; modal lets you choose remote or local version

📴

Offline Editing

Write while offline → IndexedDB queue → auto-sync on reconnect

// Socket.IO flow

// User A types in editor
socket.emit('document:edit', {
  docId,
  content: newContent,
  workspaceId,
  timestamp: Date.now()
});

// Server broadcasts to all others
socket.to(workspaceId).emit(
  'document:updated',
  { docId, content, editedBy }
);

// Conflict check on receive
if (timeDiff < 2000 &&
    content !== lastRemote) {
  showConflictModal();
}

Personal Socket Room

4 Trigger Types

📎 File uploaded · ✅ Task created · 🔄 Task updated · 👋 User joined

🗄️

Persisted in MongoDB

Stored in notifications collection; latest 50 returned per user

Security
Security-First Design
LayerMeasureDetails
🔏 Passwordsbcrypt hashing12 salt rounds — computationally expensive to brute-force
🍪 SessionsJWT HttpOnly cookieNot accessible to JavaScript; 7-day expiry
🚦 Rate Limitingexpress-rate-limitAuth: 20 req / 15 min · General API: 200 req / min
🛡️ CSRFOrigin/Referer checkServer verifies header on every state-changing request
💉 NoSQL InjectionInput type-checkingTypes validated before any DB query
📁 File SafetyMIME allowlist + size capOnly safe types; max 10 MB; enforced by Multer
🗂️ Path Traversalpath.basename()DB-stored filename used for all actual disk operations
👁️ Access ControlMembership checksEvery API endpoint verifies workspace membership + role
